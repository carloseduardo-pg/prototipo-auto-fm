# `grid_remessa` — Remessas do dia

Rota: `/remessas`. Mockup: `referencia-ui/remessas.html`.

Colunas: Remessa, Nota fiscal, Destino, Fontes (OTM / SFTP / planilha), Situação, Valor do frete, ação.

Busca por remessa, nota ou destino. Topbar: última coleta + “Coletar agora”.

A coluna Fontes é a razão do produto: o estado das três origens que o RPA alimenta.
