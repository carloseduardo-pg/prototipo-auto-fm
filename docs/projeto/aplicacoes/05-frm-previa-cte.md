# `frm_previa_cte` — Conferir antes de emitir

Drawer modal em Remessas. Mockup: `referencia-ui/remessas.html` (`#drawer`).

Mostra payload reconciliado, estado das fontes, divergência se houver, campo motorista. Botões: Cancelar · Emitir CT-e.

Emitir desabilitado se fontes incompletas ou divergência. Confirmado: chama API GW e mostra sucesso/falha. Sem animação autônoma.
