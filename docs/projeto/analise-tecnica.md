# Análise técnica — Portal FM Transportes

Síntese para o scaffold. Fontes: Relatório Geral (02/09/2026), ata 01/09, campo 19/08, mockup `modelo-inicial`.

## Decisão de solução

Plataforma própria. GW fica. Integração por API, não por digitação. Primeiro caso: CT-e.

## Foco do 1º entregável (2026-09-11)

Cerne da operação: remessas, três fontes, prévia, motorista. Manifesto fora. API GW e cadastro institucional (CNPJ) fora. Dados: RPA (Vini) + seed.

## Riscos adiados (não bloqueiam o protótipo)
