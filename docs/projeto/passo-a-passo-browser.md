# Passo a passo no browser

## Agora (mockup)

1. Abrir `referencia-ui/index.html`.
2. Preencher e-mail e senha quaisquer (protótipo).
3. Início → Remessas.
4. Abrir uma linha pronta e ver a prévia. Linhas com falha/divergência não emitem.

## Depois do scaffold

1. `npm run install:all && npm run setup`
2. `npm run dev` (API + UI)
3. Login com o usuário seed (campos vazios de propósito)
4. Conferir `/api/docs`
5. Percorrer Início e Remessas contra este guia e o mockup
