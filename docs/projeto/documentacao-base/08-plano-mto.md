## O que o plano é

Planejamento + metodologia **MTO** (Método de Transformação por Oportunidades). Foco das semanas: imersão para achar automação, otimizar fluxos e melhorar sistemas existentes.

Objetivos: mapear áreas; documentar rotinas; achar tarefas manuais repetitivas; avaliar soluções atuais.

## Filosofia MTO (resumo)

Quatro perguntas em toda iniciativa: o que melhorar; por que importa; qual a melhor solução; como medir. Princípios: entender antes de automatizar; tecnologia é consequência; valor acima da tecnologia; governança gera velocidade; evolução contínua.

Prottus facilita e executa a transformação **sem** substituir decisões de negócio. FM valida processos, prioriza, homologa e adota.

Ciclo: Descobrir → Conceber → Construir → Validar → Evoluir. Entregas incrementais ~quinzenais.

## Governança operacional

- Portfólio no **Asana** (fonte única de acompanhamento no plano).
- Iniciativa só vai a desenvolvimento com processo documentado, objetivo, solução validada, esforço, benefícios e prioridade do comitê.
- Dedicação prevista da FM: ~4h presenciais/semana.
- Reunião semanal de acompanhamento (1h). Reunião mensal de evolução (~2h, presencial).

Critérios de conclusão no plano: produção + homologação formal + docs + usuários orientados + indicadores iniciais. Isso é o MTO completo — **não** o critério do protótipo atual.
