# Mockup `modelo-inicial`

Não está dentro de `FM Transportes/` (fica no irmão `modelo-inicial/`). Copiado para `referencia-ui/` neste repo. HTML/CSS/JS puro.

## O que o HTML cobre

Login, Início (resumo da última coleta), Remessas (lista com três fontes), drawer de prévia, design system / tokens, menu com Manifestos / Indicadores / Automações.

## Falso no mockup

- Login aceita qualquer credencial
- 18 remessas fixas no JS
- “Coletar agora” e “Emitir” com `setTimeout`
- Manifestos / Indicadores / Automações só no menu

## Verdadeiro (alinhar com as atas)

- Paleta da logo FM (`#0079FC`, asfalto `#3A3A38`, fundo `#F5F5F7`)
- Três fontes na linha (OTM, SFTP, planilha)
- Prévia humana antes de emitir
- Emitir desabilitado (não escondido) se as fontes não conferem
- Campo de motorista na prévia
